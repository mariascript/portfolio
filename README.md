# Maria Pereira Portfolio

Bilingual (EN/PT-BR) developer portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- React Icons

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Personalization Checklist

- Update profile links, email, and copy in `lib/content.ts`
- Update tech stack and certificates in `lib/stack.tsx`
- Replace `public/curriculo-maria-pereira.pdf` with your final resume
- Replace `public/profile.webp` with your photo

## Build

```bash
npm run build
```

## Deployment

Project is deployment-ready for Vercel.
